美股买卖点与仓位监控（Windows 免安装版）
========================================

系统要求
--------
- Windows 10 或 Windows 11，64位
- 可访问 Alpaca 和 Yahoo Finance 的网络
- Alpaca API Key 与 Secret（免费 Paper 账户即可读取 IEX 行情）
- 或 Yahoo Finance（无需密钥）
- 或 Massive / Polygon API Key
- 或已安装并登录的 IB Gateway
- 不需要安装 Python

启动方法
--------
1. 将整个 StockSignalMonitor 文件夹解压到本地磁盘。
2. 双击 StockSignalMonitor.exe。
3. 点击“配置密钥”。
4. 在记事本中把 replace_with_your_key 和 replace_with_your_secret 替换为自己的 Alpaca 凭证，保存并关闭。
5. 在软件中添加股票、填写持仓及风控参数。
6. 点击“启动流式监控”。

数据源
------
- Alpaca IEX：实时IEX行情，需要Alpaca Key与Secret。
- Yahoo Finance：无需密钥，适合个人研究使用。
- Massive / Polygon：需要Key，可按订阅使用延迟或实时行情。
- IBKR Gateway：连接本机Gateway，Paper常用4002端口，Live常用4001端口。

IBKR使用前，请在 Gateway 的 Configure / Settings → API → Settings 中启用Socket API，并保持Read-Only API开启。默认行情类型3会在有权限时使用实时数据，否则申请延迟数据。实时API行情可能需要单独的市场数据订阅。

重要：不要只复制 exe 文件。
StockSignalMonitor.exe 必须与同目录的 _internal 文件夹一起保留。

数据保存位置
------------
软件会把密钥、监控列表、持仓、风险参数及信号记录保存在：

%LOCALAPPDATA%\StockSignalMonitor

升级软件时只需替换解压后的程序目录，不会覆盖上述个人配置。

界面术语
--------
- 买入/突破加仓点：没有持仓时作为候选买入触发；已有持仓时作为强势突破加仓触发。
- 风险减仓点：价格跌至该水平时的机械风险控制参考。
- 盈利减仓点 2R / 3R：按持仓均价与每股风险计算的两档分批盈利目标。
- 到价后加/减多少股：同时受账户单笔风险和单股资金上限约束的规则示例。

历史日线不足
------------
- 205日及以上：标准 SMA50 / SMA200 模型。
- 65至204日：临时使用 SMA20 / SMA50，标记为中等质量。
- 35至64日：临时使用 SMA10 / SMA30，标记为较低质量。
- 少于35日：只显示实时价格，暂停所有买卖点和仓位意见。

请查看界面的“数据/模型”列，不要把降级模型与完整历史模型视为相同置信度。

安全边界
--------
- 软件只载入市场数据客户端。
- 软件不包含下单、改单或撤单功能。
- API Key 和 Secret 不包含在分发包内。
- 不要把 %LOCALAPPDATA%\StockSignalMonitor\.env 分享给他人。

行情说明
--------
免费 Alpaca 数据默认使用实时 IEX 成交，不等同于覆盖美国所有交易所的完整 SIP 行情。
非交易时段或没有新成交时，实时日志不会持续产生新价格记录。

风险提示
--------
所有买卖点、止损、盈利目标和仓位意见均为透明的机械规则示例，不保证收益，也不能替代持牌专业人士根据个人财务状况提供的建议。

常见问题
--------
1. Windows SmartScreen 提示未知发布者
   这是因为本地生成的程序没有商业代码签名。确认文件来自可信来源后，可选择“更多信息”再运行。

2. 点击启动后提示缺少密钥
   点击“配置密钥”，填写并保存 Alpaca API Key 与 Secret，然后重新点击启动。

3. 股票名称显示为股票代码
   名称来自后台网络查询；网络不可用时会暂时使用股票代码，不影响行情监控。

4. 想迁移自己的设置
   在旧电脑关闭软件，将 %LOCALAPPDATA%\StockSignalMonitor 文件夹复制到新电脑的相同位置。
