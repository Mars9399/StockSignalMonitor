# 美股买入点与止损点只读监控

这个监控器只连接 Alpaca Market Data API。它不会加载交易客户端，也没有创建、提交或取消订单的代码。

## 图形界面与流式行情（推荐）

运行：

```powershell
cd C:\Users\tmscl\Documents\Codex\2026-08-06\sou-su\outputs
& "C:\Users\tmscl\AppData\Local\Programs\Python\Python313\python.exe" .\signal_monitor_gui.py
```

在窗口顶部输入股票代码并点击“添加”，也可以选择表格中的股票后点击“移除所选”。点击“启动流式监控”后，程序通过 Alpaca WebSocket 接收 IEX 实时成交。监控列表会保存到 `watchlist.json`，下次打开自动恢复。

表格包含股票代码和股票名称。默认股票名称内置，新增股票的名称通过 Yahoo Finance 在后台查询，并缓存到 `stock_names.json`。

窗口底部的“后台实时日志”每只股票最多约10秒记录一次最新成交、信号状态、买点、风控线和仓位意见；状态发生变化时会立即记录。日志只保留在当前窗口，买入提示仍会另外写入 `signal_alerts.csv`。

修改监控列表时，如果行情已经启动，请点击“停止”，然后重新启动，以应用新的流式订阅。

### 支持的数据接口

在界面顶部“数据源”下拉框选择：

- `Alpaca IEX`：API Key + Secret；IEX 实时逐笔成交。
- `Yahoo Finance`：无需密钥；历史日线与新版 WebSocket，适合个人研究，不保证交易所级稳定性。
- `Massive / Polygon`：需要 API Key；支持延迟或实时 WebSocket，权限由订阅方案决定。
- `IBKR Gateway`：连接本机已经登录的 IB Gateway，通过 TWS Socket API 获取日线和实时/延迟行情。

点击“配置密钥”可编辑所有数据源参数。切换数据源时请先停止监控，然后重新启动。

### IBKR Gateway 配置

1. 安装并登录 IB Gateway。
2. 打开 `Configure / Settings → API → Settings`。
3. 启用 Socket API，并保持 `Read-Only API` 开启。
4. 确认 Socket Port：Paper Gateway 常用 `4002`，Live Gateway 常用 `4001`。
5. 在软件点击“配置密钥”，设置：

```text
IBKR_HOST=127.0.0.1
IBKR_PORT=4002
IBKR_CLIENT_ID=17
IBKR_MARKET_DATA_TYPE=3
```

`IBKR_MARKET_DATA_TYPE`：1实时、2冻结、3延迟/有权限时自动实时、4延迟冻结。实时数据通常需要相应市场订阅；没有订阅时建议使用3。

软件不会保存或处理IBKR用户名、密码，也没有调用IBKR下单方法。

### 持仓与风控输入

1. 在表格中选择股票。
2. 填写持仓均价和持股数量，然后点击“保存持仓”。
3. 填写账户规模、允许的单笔风险百分比以及单只股票资金上限，点击“保存风控”。

默认单笔风险为账户的 1%，单只股票资金上限为账户的 10%。持仓保存在本地 `positions.json`，风险参数保存在 `risk_settings.json`。

### 界面指标含义

- `买入点`：前20个日线周期最高价形成的突破水平。
- `止损/风控线`：未持仓时为买入点下方2倍ATR；已持仓时使用价格、ATR和50日均线计算的动态风险线。
- `盈利卖点 2R / 3R`：以持仓均价和每股风险R计算的两个分批止盈水平。
- `等待突破`：趋势符合，但离买点超过3%。
- `接近买点`：趋势符合，离买点不超过3%。
- `买入提示`：价格已经达到突破水平。
- `趋势不符`：价格或均线趋势过滤未通过。
- `仓位规则意见`：根据风险预算和单股资金上限计算的机械规则示例，不是保证收益的投资建议，也不会自动执行。

### 历史日线不足时

软件不会用不足的数据硬套200日均线，而是按可用交易日分级处理：

- 205日及以上：标准模型 `SMA50 / SMA200`，质量标记“标准”。
- 65–204日：降级为 `SMA20 / SMA50`，质量标记“降级·中等”。
- 35–64日：降级为 `SMA10 / SMA30`，质量标记“降级·较低”。
- 少于35日：只显示实时价格和历史天数，买入点、风险减仓点、盈利减仓点及加减仓意见全部暂停。

界面的“数据/模型”列会显示实际日线数量、使用的均线模型和信号质量。降级模型适用于新上市股票的临时观察，但不能与完整200日趋势模型视为同等置信度。

## 默认规则

- 趋势过滤：现价高于 200 日均线，并且 50 日均线高于 200 日均线。
- 买入点：此前 20 个日线周期的最高价。
- 买入提示：实时价格达到或突破买入点，并且趋势过滤通过。
- 止损点：买入点减去 2 倍 14 日 ATR。
- 相同股票同一天只提示一次；价格跌回买入点下方后可重新触发。

该规则是一个可修改的默认技术策略，不代表投资建议。
