# 美股买入点与止损点只读监控

这个监控器支持 Alpaca、Yahoo Finance、Massive/Polygon 与 IBKR/TWS 只读数据接入。它没有创建、提交或取消订单的代码。

## 图形界面与流式行情（推荐）

运行：

```powershell
cd C:\Users\tmscl\Documents\Codex\2026-08-06\sou-su\outputs
& "C:\Users\tmscl\AppData\Local\Programs\Python\Python313\python.exe" .\signal_monitor_gui.py
```

在窗口顶部输入股票代码并点击“添加”，也可以选择表格中的股票后点击“移除所选”。点击“启动流式监控”后，程序通过 Alpaca WebSocket 接收 IEX 实时成交。监控列表会保存到 `watchlist.json`，下次打开自动恢复。

表格包含股票代码和股票名称。默认股票名称内置，新增股票的名称通过 Yahoo Finance 在后台查询，并缓存到 `stock_names.json`。

窗口底部的“后台实时日志”每只股票最多约10秒记录一次最新成交、信号状态、买点、卖点和仓位意见；状态发生变化时会立即记录。日志只保留在当前窗口，买入和卖出提示会另外写入 `signal_alerts.csv`。

“暴涨暴跌 TOP10”页先使用 Yahoo 美股全市场榜单筛选候选股票，再用最新 1 分钟行情校准价格、涨跌幅并重新排序。系统每 60 秒自动更新两侧各 10 只股票，也可点击“立即刷新”，并显示买入点、卖出点与“买入机会 / 接近买点 / 等待回踩 / 回避”等直接判断。选中股票后可加入自选；该扫描独立运行，不会阻塞自选股流式行情。行情时间列代表数据源实际时间，休市时不会被标成实时行情。

“全市场股票”页按股票代码分页浏览 Yahoo 美国市场证券，每页 100 只，也可按代码或名称搜索。右键选中的股票并点击“加入自选”，或直接双击条目，即可放入监控列表。全量结果采用分页读取，不会一次加载数千行阻塞界面。

Windows 的概览、自选、TOP10 与全市场列表在价格上跳后整行文字保持绿色、下跳后保持红色；macOS 的对应价格文字采用同样的方向色。颜色保持到下一次价格方向变化，不使用延时清除，因此快速连续行情不会被旧定时器覆盖。

顶部账户栏通过 TWS 只读接口显示当前账户、净资产、可用资金、购买力、现金和未实现盈亏。“暂时隐藏 / 暂时显示”只影响当前软件界面，不修改 TWS 设置，也不会把偏好保存到磁盘。点击“刷新账户”或“重新读取持仓”可重新读取。

在“监控概览”中双击任意股票，可通过 TWS 打开最近两日的 5 分钟行情图。图中显示 K 线、收盘走势、突破买入线和卖出触发点。若 TWS 没有该股票的行情订阅，窗口会直接显示权限或连接错误。

“即时买入概率*”与“建议减持概率*”按百分比显示短线操作评分。买入评分主要考虑当前价格在 10 日通道中的位置、是否突破、5/10 日动量、RSI、量能和通道风险，并在单股仓位过高、组合资金占用过高或 TWS 可用资金偏低时下调。减持评分只在有持仓时计算，进一步考虑成本盈亏、保护线、趋势转弱、单股仓位和账户余量；无持仓固定显示 `0% 无持仓`。历史或实时数据过期时显示 `—`。

带星号的“概率”是 0–100 的规则评分，用于把多项短线信息压缩成直观强弱，不是统计回测得出的真实获利概率，也不承诺相同百分比的成功率。原有突破买入线和卖出触发点仍是一级判断，评分不会改变触发条件。

## 界面设置

点击顶部操作栏的“界面设置”可修改：

- 初始窗口宽度和高度；
- 常规界面文字大小与列表文字大小；
- 列表行高和后台日志区域高度；
- 是否启动时最大化、退出时记住当前尺寸；
- 是否默认显示账户明细；
- 是否在进入 TOP10 页时自动开始扫描；
- 是否在关闭软件前再次确认。

点击“保存并应用”后，字体、列表行高、日志高度和窗口尺寸会立即更新，其余启动选项也会用于下次运行。“恢复默认值”只负责填入默认参数，仍需点击“保存并应用”。配置保存在 `ui_settings.json`，不会写入账户、行情或交易数据。

macOS 2.5.0 的“设置 → 界面”提供初始窗口宽高、文字缩放、列表行高、日志高度、日志显隐和启动后自动监控。macOS 概览与股票详情也显示“即时买入概率* / 建议减持概率*”，算法含义与 Windows 相同；设置通过系统 `UserDefaults` 保存在当前用户账户中。

修改监控列表时，如果行情已经启动，请点击“停止”，然后重新启动，以应用新的流式订阅。

### 支持的数据接口

在界面顶部“数据源”下拉框选择：

- `Alpaca IEX`：API Key + Secret；IEX 实时逐笔成交。
- `Yahoo Finance`：无需密钥；历史日线与新版 WebSocket，适合个人研究，不保证交易所级稳定性。
- `Massive / Polygon`：需要 API Key；支持延迟或实时 WebSocket，权限由订阅方案决定。
- `IBKR Gateway`：连接本机已经登录的 IB Gateway，通过 TWS Socket API 获取日线和实时/延迟行情。

点击“配置密钥”可编辑所有数据源参数。切换数据源时请先停止监控，然后重新启动。

### IBKR Gateway 配置

1. 安装并登录 IB Gateway。
2. 打开 `Configure / Settings → API → Settings`。
3. 启用 Socket API，并保持 `Read-Only API` 开启。
4. 确认 Socket Port：Paper Gateway 常用 `4002`，Live Gateway 常用 `4001`。
5. 在软件点击“配置密钥”，设置：

```text
IBKR_HOST=127.0.0.1
IBKR_PORT=4002
IBKR_CLIENT_ID=17
IBKR_MARKET_DATA_TYPE=3
```

`IBKR_MARKET_DATA_TYPE`：1实时、2冻结、3延迟/有权限时自动实时、4延迟冻结。实时数据通常需要相应市场订阅；没有订阅时建议使用3。

软件不会保存或处理IBKR用户名、密码，也没有调用IBKR下单方法。

### 持仓与风控输入

1. 在表格中选择股票。
2. 填写持仓均价和持股数量，然后点击“保存持仓”。
3. 填写账户规模、允许的单笔风险百分比以及单只股票资金上限，点击“保存风控”。

默认单笔风险为账户的 1%，单只股票资金上限为账户的 10%。持仓保存在本地 `positions.json`，风险参数保存在 `risk_settings.json`。

### 界面指标含义

- `突破买入线`：此前 10 个完整交易日的最高价；它通常高于尚未触发时的现价。只有实时价格向上达到或突破该线时才提示买入，低于该线表示等待确认，不代表都适合买入。
- `卖出点`：此前 10 个完整交易日的最低价；实时价格达到或下破时提示卖出。
- `可选保护线`：只对已有持仓生效；若高于通道卖出点，则使用更紧的保护线。留空不影响买卖提示。
- `等待 / 接近买点`：价格仍在通道内，显示到触发点的直观距离。
- `仓位意见`：风险预算和单股资金上限只用于估算参考股数，不改变买入或卖出方向。

### 历史日线不足时

少于 20 根完整日线时只显示价格和历史天数，暂停买卖意见；达到 20 根后统一使用 10 日高低点模型，不再因为长均线历史不足而延迟提示。

## 默认规则

- 买入点：此前 10 个完整日线周期的最高价。
- 卖出点：此前 10 个完整日线周期的最低价。
- 买入提示：实时价格达到或突破买入点。
- 卖出提示：实时价格达到或跌破卖出点。
- 买入和卖出两种状态分别去重；行情流中断会自动重连。

该规则是一个可修改的默认技术策略，不代表投资建议。
