# Stock Signal Monitor

只读美股买卖点监控工具。支持 Windows、macOS、iPhone 与 iPad，提供 Alpaca IEX、Yahoo Finance、Massive/Polygon 与 IBKR 数据接入，以 10 日价格通道直接提示买入点和卖出点，不创建或提交订单。macOS 客户端可直接通过本机 TWS Socket API 同步只读持仓，无需 Client Portal Gateway。

## 目录

- `signal_monitor_gui.py`：图形界面入口
- `signal_monitor.py`：指标和信号计算
- `data_providers.py`：行情接口适配层
- `market_movers.py`：美股全市场涨跌榜扫描与买入机会判断
- `apple/`：macOS 与 iOS/iPadOS 原生 SwiftUI 版本及共享 Swift 核心
- `docs/`：使用与部署说明
- `dist/`：已经构建好的 Windows 发布包
- `.env.example`：配置模板，不包含真实密钥

## 开发运行

1. 安装 Python 3.11 或更高版本。
2. 在项目目录运行 `setup.ps1` 安装依赖。
3. 将 `.env.example` 复制为 `.env`，按需要填写行情接口配置。
4. 运行 `start.ps1`。

## 构建 Windows 版本

运行 `build.ps1`。构建结果写入项目的 `build-output` 目录。

Windows 版支持“显示全部 / 只显示持仓”、重新读取持仓、清除全部本地持仓及独立自选列表（数量、成本、市值）。监控概览增加“即时买入概率*”和“建议减持概率*”：买入评分综合突破位置、短线动量、RSI、量能和账户余量；减持评分再综合持仓盈亏、个股仓位、组合资金占用及 TWS 可用资金。百分比是 0–100 的即时操作评分，并非经过样本校准的真实胜率。价格上跳后整行文字保持绿色、下跳后保持红色，直到下一次反向价格变化；不使用定时闪烁，因此连续行情不会被旧计时器覆盖。概览、自选、TOP10 和全市场列表采用同一规则。顶部显示 TWS 当前账户的净资产、可用资金、购买力、现金和未实现盈亏，并可在本次运行内临时隐藏或显示。“暴涨暴跌 TOP10”页每 60 秒读取 Yahoo 美股全市场榜单，再用最新 1 分钟行情校准价格、涨跌幅和名次；也可点击“立即刷新”。“全市场股票”页分页浏览约两万只 Yahoo 美国市场证券，支持代码/名称搜索，选中后可右键加入自选。监控概览中双击股票会通过 TWS 打开最近两日的 5 分钟行情图，并叠加突破买入线和卖出触发点。选择 `IBKR TWS + Yahoo 行情` 后，启动时从 TWS 读取持仓，行情由 Yahoo 提供。在 `.env` 配置 `TWS_HOST`、`TWS_PORT`（模拟账户 7497，实盘 7496）、`TWS_CLIENT_ID` 和可选的 `TWS_ACCOUNT_ID`。TWS 中启用 Socket API 与 Read-Only API，并为图表准备相应的美股行情权限。持仓支持美元股票多头和碎股；已清仓记录会移除，读取失败保留原有数据。

“界面设置”可调整初始窗口宽高、界面文字、列表文字、列表行高和日志区域高度，并提供启动最大化、退出时记住窗口大小、账户明细默认显示、TOP10 自动扫描及关闭确认。设置保存在用户数据目录的 `ui_settings.json`，字体、行高和尺寸保存后立即应用。

两端的独立自选列表读取应用保存的股票并合并 TWS 持仓；不直接导入 TWS Mosaic/Classic 自选页面。Windows 构建会在推送 main 后由 GitHub Actions 自动执行，成功后在该次运行的 Artifacts 中下载 `StockSignalMonitor-Windows`。

## 构建 Apple 版本

在安装 Xcode 16 与 XcodeGen 的 macOS 上运行：

```bash
./apple/scripts/bootstrap.sh
./apple/scripts/test_apple.sh
```

完整说明见 [`apple/README.md`](apple/README.md)。Codex 的 Run 操作会调用 `./script/build_and_run.sh` 构建并启动 macOS 客户端。

macOS 2.5.0 已与 Windows 的核心短线判断对齐：概览和详情均显示即时买入/建议减持规则评分，实时价格文字按最近一次变化方向持续显示绿色或红色，并在设置窗口提供初始窗口大小、文字缩放、列表行高、日志尺寸与自动启动选项。macOS 同样提供可分页、可搜索并支持右键加入自选的“全市场股票”入口。两端仍只读行情和持仓，不提供下单接口。

## 数据与安全

### 决策可靠性规则

- 核心信号只比较实时价格与此前 10 个完整交易日的最高价、最低价：上破提示买入，下破提示卖出，中间状态显示距最近触发点。
- 至少需要 20 根完整日线。均线只作为辅助数据显示，不再阻止买卖提示；2R/3R 分批策略已退出主流程。
- 初始风险线为可选保护线；设置后只会收紧持仓卖出点，留空仍可正常给出买卖意见。
- TWS 同步的成本或数量变化时会清除旧保护线。提示不代表实际成交，本软件不执行订单。
- Windows/macOS/iOS 统一保留碎股。实际建议减仓数量不超过持有数量。
- 指标仅采用纽约当前日期之前的日线，排除当日未完成日线；跨日重新加载历史。
- 操作提示要求行情时间戳不超过 180 秒、非未来异常时间，且处于纽约工作日 04:00–20:00；缺少时间戳、历史未更新或监控停止均降为仅观察。
- 历史最后一根完整日线允许距当前 1–4 个日历日，以容纳周末和常见休市日；提前收盘等特殊时段仍以数据源时间戳为准。
- 行情流中断或 180 秒无市场事件时自动重连；IBKR 使用成交时间字段，不再把无时间戳的价格当作实时买卖信号。

`.env`、持仓、风险设置、告警记录、监控状态和缓存均为本机运行数据，已排除在版本控制和发布源码包之外。迁移到其他电脑时，请在目标电脑重新填写 `.env`。

本软件仅用于行情监控和技术分析辅助，不构成投资建议。
